# Soporte

Incluya en toda solicitud de soporte:

- Versión o commit del paquete.
- Sistema operativo y versiones de Python, Node, Docker y Docker Compose.
- Pasos para reproducir el problema.
- Salida de `python manage.py check` y `docker compose ps`.
- Logs sin secretos, tokens, cookies ni datos personales.

No comparta archivos `.env`, dumps de producción ni credenciales de pago.

El soporte cubre instalación, configuración y defectos reproducibles del
paquete entregado. Personalizaciones de marca, reglas de negocio, integraciones
y despliegues de infraestructura se evalúan como trabajo adicional.
